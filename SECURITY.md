# Reporting a problem

For ordinary bugs, open an issue with the app version, Windows version, and
reproduction steps. Redact device identifiers, usernames, file paths, and photos.
Do not upload recovery folders or firmware files.

For a vulnerability that could permit unintended device writes, use the GitHub
repository's private vulnerability-reporting feature if enabled. Do not post
exploit instructions or private device data in a public issue.

Supported release scope: 0.1.0 beta, Noble NB4+ EN/EU 1.0.31-4, three stock slots.
EU package import/export is verified; EU hardware operation awaits a device check.
